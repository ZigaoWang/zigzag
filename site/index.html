Why

When Arc announced it would shut down on December 22, I didn’t want to give up my sidebar. My friend, who calls most software trash, said: “I trust you. You can make one. Make it good.”

So I did. No account and no server it depends on, so nobody can switch it off. If I ever stop, the code is open for anyone to carry on.

Questions

Is Zigzag just an Arc copy?

Arc showed a lot of people that a browser could feel good, and Zigzag is openly inspired by that. But it’s built from scratch, on Safari’s engine instead of Chrome’s, with its own design, and things Arc never had: tabs that tidy themselves, built in ad blocking, and a password manager that imports from any browser. Zigzag isn’t affiliated with The Browser Company.

Will Zigzag shut down like Arc?

It can’t be switched off. There’s no account, and the only server is the update feed. If it went away, Zigzag would keep working on your Mac. Security updates for the engine come straight from Apple with macOS.

Is Zigzag finished?

Not yet. It’s in beta, which means it works well for everyday browsing, but some things are still being polished. Updates install automatically, so it keeps getting better on its own.

Does it work with Chrome extensions?

Most popular ones, installed straight from the Chrome Web Store. Some can’t work outside Chrome, and Zigzag tells you upfront instead of breaking silently.

Why Safari’s engine?

It’s already on your Mac, so Zigzag doesn’t have to ship one, and Apple fixes its security issues in macOS updates.

Which Macs does it run on?

macOS 15.4 or later.
