Introducing Zigzag

Zigzag is a Mac browser with your tabs in a sidebar, grouped into spaces. It’s written in Swift and AppKit around WebKit, the engine inside Safari, so it opens quickly, stays light, and gets engine security fixes with every macOS update.

It’s free, open source, and there’s no account. If you’re leaving Arc, your spaces, pinned tabs and passwords come with you.

Spaces keep work and life apart.

Each space has its own pinned tabs, folders and color. Swipe on the sidebar to move between them.

The essentials, done properly.

Ad blocking About 123,000 EasyList and EasyPrivacy rules, built into the engine and on by default.

Chrome extensions Installed from the Chrome Web Store. 1Password works; a few extension APIs aren’t there yet.

Passwords and passkeys Kept in your Keychain, synced by iCloud Keychain, filled with Touch ID.

Translation Whole pages, translated on your Mac by Apple’s Translation.

Also A PDF viewer, full-page screenshots, picture in picture, private windows and Web Inspector.

17 MB, all of it.

Zigzag doesn’t ship its own engine. It uses the WebKit that’s already part of macOS, so it’s a fraction of the size.

Coming from Arc

File › Import from Another Browser reads Arc’s own files: spaces, pinned tabs, folders, Favorites and history. Passwords come over too, once macOS asks your permission. Open tabs stay behind, so you start with a clean sidebar.

Chrome, Safari, Firefox, Dia, Edge, Brave, Vivaldi, Opera and Zen import the same way.

What Zigzag sends

There’s no account, analytics or telemetry. On its own, Zigzag checks zigzagbrowser.com for updates once a day, fetches search suggestions as you type (without cookies, and you can turn them off), and loads site icons.

That’s all of it, and the README lists every connection in detail.

Why

In October 2026, The Browser Company announced Arc would shut down on December 22. Arc accounts stop working that day, and with them, a lot of people’s favorite browser.

I was one of them. So was my friend, who isn’t a browser person at all and usually calls everything trash. This time he said: “I trust you. You can make one. Make it good.”

So I did. Zigzag keeps what made Arc feel good: the sidebar, spaces, a page that feels like it’s floating, and a browser that gets out of your way. It’s built from scratch on Safari’s engine, so it’s light on your Mac and secure, with updates straight from Apple.

And it can’t happen again. There’s no account, and the only server is the update feed, so nobody can switch Zigzag off. The code is open source under the Apache License 2.0. If I ever stop working on it, anyone can pick it up and keep going.

Zigzag is free, made by one person, and built for everyone who loved Arc and doesn’t want to start over.

Questions

Is Zigzag just an Arc copy?

Arc showed a lot of people that a browser could feel good, and Zigzag is openly inspired by that. But it’s built from scratch, on Safari’s engine instead of Chrome’s, with its own design, and things Arc never had: tabs that tidy themselves, built in ad blocking, and a password manager that imports from any browser. Zigzag isn’t affiliated with The Browser Company.

Will Zigzag shut down like Arc?

It can’t be switched off. There’s no account, and the only server is the update feed. If it went away, Zigzag would keep working on your Mac. Security updates for the engine come straight from Apple with macOS.

Do I need an account?

No. Download it and go.

Is Zigzag finished?

Not yet. It’s in beta, which means it works well for everyday browsing, but some things are still being polished. Updates install automatically, so it keeps getting better on its own.

Is it free?

Yes.

Can I bring my stuff from Arc?

Yes, in one click: spaces, pinned tabs, Favorites, history, and passwords. Chrome, Safari, Dia, Edge, Brave, Vivaldi, Opera, Firefox, and Zen work too.

Does it work with Chrome extensions?

Most popular ones, installed straight from the Chrome Web Store. Some can’t work outside Chrome, and Zigzag tells you upfront instead of breaking silently.

Why Safari’s engine?

It’s already on your Mac, so Zigzag doesn’t have to ship one, and Apple fixes its security issues in macOS updates.

Is my data private?

Yes. There’s no account, no analytics and no telemetry, and nothing about how you browse is sent to me. Zigzag checks zigzagbrowser.com once a day for updates, sending only its version. Passwords live in your Mac’s Keychain and sync only through your own iCloud. Everything Zigzag connects to is listed on GitHub.

Is Zigzag open source?

Yes. The code is under the Apache License 2.0, on GitHub. Read it, build it, fork it. The Zigzag name and icon aren’t part of the license, so a fork needs its own.

Which Macs does it run on?

macOS 15.4 or later.
