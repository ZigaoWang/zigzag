常见问题

Zigzag 只是 Arc 的翻版吗？

Arc 让很多人看到，浏览器也可以用着舒服，Zigzag 也大方承认受到了它的启发。但 Zigzag 是从零开始写的，用的是 Safari 的引擎而不是 Chrome 的，有自己的设计，还有 Arc 从来没有的东西：会自己整理的标签页、内置的广告拦截，以及能从任何浏览器导入的密码管理器。Zigzag 与 The Browser Company 没有关联。

Zigzag 会像 Arc 一样停止运营吗？

它关不掉。没有账户，唯一的服务器只有更新源和一份很短的广告拦截修复列表。就算它们没了，Zigzag 在你的 Mac 上也照样能用。引擎的安全更新由 Apple 随 macOS 直接提供。

Zigzag 做完了吗？

还没有。它还是 Beta 版，日常浏览已经很好用，但有些地方还在打磨。更新会自动安装，所以它会自己越来越好。

能用 Chrome 扩展吗？

大多数热门扩展都能用，直接从 Chrome 网上应用店安装，Tampermonkey 和你的用户脚本也能用。有些扩展离开 Chrome 就用不了，Zigzag 会提前告诉你，而不是悄悄失效。

为什么用 Safari 的引擎？

它本来就在你的 Mac 上，所以 Zigzag 不用再附带一个，而且 Apple 会在 macOS 更新中修复它的安全问题。

能在哪些 Mac 上运行？

macOS 15.4 或更高版本。
