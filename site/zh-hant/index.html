常見問題

Zigzag 只是 Arc 的翻版嗎？

Arc 讓很多人看到，瀏覽器也可以用起來很舒服，Zigzag 也大方承認受到了它的啟發。但 Zigzag 是從零開始寫的，用的是 Safari 的引擎而不是 Chrome 的，有自己的設計，還有 Arc 從來沒有的東西：會自己整理的分頁、內建的廣告阻擋，以及能從任何瀏覽器匯入的密碼管理工具。Zigzag 與 The Browser Company 沒有關聯。

Zigzag 會像 Arc 一樣停止營運嗎？

它關不掉。沒有帳號，Zigzag 自己的伺服器只有更新來源和一份很短的廣告阻擋修正清單。就算它們不見了，Zigzag 在你的 Mac 上也照樣能用。引擎的安全性更新由 Apple 隨 macOS 直接提供。

Zigzag 做完了嗎？

還沒有。它還是 Beta 版，日常瀏覽已經很好用，但有些地方還在打磨。更新會自動安裝，所以它會自己越來越好。

能用 Chrome 延伸功能嗎？

大多數熱門延伸功能都能用，直接從 Chrome 線上應用程式商店安裝，Tampermonkey 和你的使用者腳本也能用。有些延伸功能離開 Chrome 就無法運作，Zigzag 會事先告訴你，而不是悄悄失效。

為什麼用 Safari 的引擎？

它本來就在你的 Mac 上，所以 Zigzag 不必再附帶一個，而且 Apple 會在 macOS 更新中修正它的安全性問題。

能在哪些 Mac 上執行？

macOS 15.4 或以上版本。
