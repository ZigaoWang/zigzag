Zigzagの紹介

タブはサイドバーに、スペースごとにまとめて。無料でオープンソースの、ネイティブなMacブラウザです。Arcユーザなら1分で移れます。

仕事と生活を、スペースで分ける。

スペースごとに、タブと色があります。スワイプで切り替えます。

基本を、きちんと。

  • 広告ブロック 内蔵、最初からオン
  • パスワードとパスキー キーチェーンとTouch ID
  • 翻訳 ページ全体を、Macの中で
  • 読み込み Arcなど16種類のブラウザから

軽量なブラウザ。

だから作りました。アカウントも、頼っているサーバもないので、誰にも止められません。もし私がやめても、コードは公開されているので、誰でも引き継げます。

よくある質問

ZigzagはArcのコピーにすぎないのですか？

Arcは、ブラウザが心地よいものになりうることを多くの人に示しました。Zigzagはそこから影響を受けたことを隠していません。でも、ゼロから作っていて、ChromeではなくSafariのエンジンを使い、独自のデザインがあり、Arcになかったものもあります。自分で片付くタブ、内蔵の広告ブロック、どのブラウザからでも読み込めるパスワードマネージャです。ZigzagはThe Browser Companyとは関係ありません。

ZigzagもArcのように終了しますか？

止められることはありません。アカウントはなく、サーバはアップデートのフィードと広告ブロックの短い修正リストだけです。それらがなくなっても、ZigzagはMacで動き続けます。エンジンのセキュリティアップデートは、macOSと一緒にAppleから直接届きます。

Zigzagは完成していますか？

まだです。ベータ版なので、普段のブラウズには十分使えますが、まだ磨いているところもあります。アップデートは自動でインストールされるので、ひとりでに良くなっていきます。

Chromeの機能拡張は使えますか？

人気のものはほとんど使えます。Chromeウェブストアから直接インストールでき、Tampermonkeyやユーザスクリプトも使えます。Chromeの外では動かないものもありますが、黙って動かなくなるのではなく、Zigzagが最初に知らせます。

なぜSafariのエンジンなのですか？

もともとMacに入っているので、Zigzagがエンジンを同梱する必要がありません。セキュリティの問題は、AppleがmacOSのアップデートで修正します。

どのMacで動きますか？

macOS 15.4以降。
