# 繁體中文用語表

Zigzag 使用 `zh-Hant` 提供繁體中文介面。請以英文原文和字串註解確認語意；簡體中文可供參考，但不要只做字形轉換。macOS 有對應功能時，優先採用繁體中文介面的用語。

| --- | --- |

| New Tab / Close Tab | 新增分頁／關閉分頁 |

- 用「你」，稱呼及語氣力求自然、直接。介面名稱在選單、提示和版本說明中應一致。
- 以全形標點寫中文；用「」標示按鈕名稱、選單路徑和使用者命名的項目，內層引號用『』。選單層級保留 `›`，省略號用 `…`。
- 中文與英文字母、數字之間加一個半形空格，例如「從 Chrome 匯入 3 個分頁」。全形標點旁不加空格。
- `%@`、`%lld`、`%2$@`、`%#@name@` 等格式參數、網址、程式碼、鍵盤符號及品牌名稱照原樣保留。若需要調整參數順序，使用原本的參數編號。
- 中文數量只有 `other` 複數形式；例如「關閉 1 個分頁」和「關閉 3 個分頁」共用格式。
