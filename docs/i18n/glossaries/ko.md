- 완전한 문장은 macOS처럼 존댓말 ‘합니다’체로 쓰고, 안내와 요청은 ‘하세요’로 끝냅니다(‘하십시오’는 쓰지 않습니다). 질문 시트의 제목은 ‘…하겠습니까?’입니다.
- 버튼과 메뉴 항목은 짧은 명사구로 씁니다(‘탭 닫기’, ‘새로운 윈도우’, ‘모두 보기’). 알림 토스트와 상태 표시는 ‘…됨’, ‘…함’, ‘…중’처럼 짧게 끝냅니다(‘즐겨찾기에 추가됨’, ‘다운로드 중…’).
- ‘당신’은 쓰지 않습니다. 주어는 대개 생략하고, 필요하면 ‘나의’(‘나의 카드’, ‘나의 스페이스’)나 ‘사용자’를 씁니다.
- 한글 맞춤법의 띄어쓰기를 따릅니다. 한글과 라틴 문자 또는 숫자 사이는 단어가 나뉘는 곳에서만 띄웁니다(‘Zigzag Mini 열기’). 조사와 단위는 붙입니다(‘Chrome에서’, ‘탭 3개’, ‘30분’, ‘100KB’).
- 자리 표시자 뒤에 오는 조사는 받침에 따라 바뀌므로 Apple처럼 ‘을(를)’, ‘이(가)’, ‘은(는)’, ‘와(과)’, ‘(으)로’를 씁니다. 조사가 바뀌지 않는 ‘에’, ‘에서’, ‘의’로 바꿀 수 있으면 그쪽을 먼저 고릅니다. Zigzag, Safari처럼 정해진 이름 뒤에는 맞는 조사를 바로 붙입니다(‘Zigzag가’, ‘Arc를’).
- 개수는 ‘명사 + 숫자 + 개’입니다(‘탭 %lld개’, ‘암호 %lld개를 내보내겠습니까?’). 한국어 복수형은 `other` 하나뿐이므로 1개와 여러 개가 같은 문장을 씁니다.
- 버튼, 메뉴 경로, 사용자가 붙인 이름은 문장 안에서 ‘ ’로 감쌉니다(‘다시 시도’, ‘설정 찾기’). 메뉴 계층은 Zigzag와 같은 `›`를 씁니다(설정 › 탭). 영어 그대로인 API 메시지만 “ ”를 둡니다.
- 문장 부호는 반각입니다. 괄호 앞에는 띄우지 않습니다(‘취소(Esc)’, ‘책갈피 파일(HTML)’). 줄임표는 `…` 한 글자입니다(‘공유…’).
- macOS의 표기를 따릅니다. ‘개인정보 보호 및 보안’과 설정의 ‘개인정보 보호’는 붙여 쓰고, Safari에서 온 ‘개인 정보 보호 윈도우’와 ‘개인 정보 보호 브라우징’은 띄어 씁니다. ‘웹 사이트’, ‘데스크탑’, ‘응용 프로그램 폴더’, ‘이중 클릭’도 Apple의 표기입니다.
- `%@`, `%lld`, `%2$@`, `%#@name@` 같은 서식 지정자, URL, 코드, 키 기호(⌘T), 브랜드 이름(Zigzag, Arc, Chrome, Safari, macOS, iCloud, Google, GitHub, 1Password)은 그대로 둡니다. 어순 때문에 인수 순서를 바꿀 때는 `%1$@`, `%2$@`처럼 원래 번호를 씁니다.
- 방문 기록 세션 이름의 때: 오전(5–12시), 오후(12–17시), 저녁(17–21시), 밤(21–24시), 새벽(0–5시). 요일과 날짜는 한국어 순서대로 날짜를 앞에 둡니다(‘10월 18일 일요일 오후’).
- 설정 찾기에만 쓰이는 검색어 문자열은 영어 단어를 그대로 두고 한국어 단어를 덧붙입니다.
- 진행 중 상태는 ‘…하는 중…’이 아니라 명사 + ‘중…’으로 짧게 씁니다(‘추가 중…’, ‘로드 중…’, ‘번역 중…’, ‘이 탭을 사용 중’). 켜고 끈 결과를 알리는 토스트는 ‘켜짐’, ‘꺼짐’이고, 설정값과 상태 표시는 ‘켬’, ‘끔’입니다.
- ‘its own’을 기계적으로 ‘자체’로 옮기지 않습니다. ‘따로’, ‘전용’, ‘고유한’으로 풀거나 생략하고(‘프로필마다 확장 프로그램… 따로 있습니다’), ‘자체 인증서’, ‘자체 스토어’, ‘Zigzag 자체 페이지’처럼 굳은 말에만 ‘자체’를 씁니다.
- ‘새’와 ‘새로운’은 섞지 않고 ‘새로운’ 하나로 씁니다(‘새로운 탭’, ‘피드의 새로운 페이지’).
- ‘That’s …’ 단계 완료 문구는 ‘이것이 바로 …입니다’입니다. AI 앱에 붙여넣는 프롬프트처럼 사용자가 말하는 문장은 ‘저’, ‘제’를 씁니다.
- 다운로드 규칙의 이름이 들어가는 자리는 ‘‘%@’ 규칙으로 전달’처럼 ‘규칙’을 붙여 조사 문제를 피합니다.
