# Lexique français

L’interface française de Zigzag est `fr`. Vérifiez le sens de chaque chaîne dans l’anglais d’origine et dans son commentaire ; les traductions chinoises peuvent aider, mais ne traduisez pas à partir d’elles. Quand macOS ou Safari ont la même fonction, reprenez les mots de l’interface française d’Apple.

- Vouvoiement partout, ton simple et direct. Les phrases complètes se terminent par un point ; les boutons, les éléments de menu et les titres sont courts et sans point.
- Majuscule au premier mot seulement, comme dans les menus d’Apple en français : « Nouvel onglet », « Fermer les autres onglets », « Réglages du site ». Les noms propres gardent leurs majuscules (Zigzag Mini, Split View, Mots de passe pour l’app d’Apple).
- Les boutons et les éléments de menu sont des verbes à l’infinitif (« Effacer l’historique… »). Les consignes à l’utilisateur sont à l’impératif (« Choisissez un dossier »). Les toasts qui décrivent un résultat sont des participes (« Lien copié », « %lld onglets fermés »).
- Points de suspension en un seul caractère `…`, sur tout élément qui ouvre une zone de dialogue, comme en anglais.
- Typographie française : espace insécable avant `:` (U+00A0), espace fine insécable avant `;`, `?`, `!` et `%` (U+202F), et espace insécable à l’intérieur des guillemets « » (U+00A0). Les guillemets anglais “ ” ne s’utilisent pas. Apostrophe typographique `’`.
- Les noms de boutons et de menus cités dans une phrase s’écrivent tels quels, sans guillemets (« cliquez sur Autoriser », « Réglages › Onglets »). Les noms donnés par l’utilisateur (un espace, un fichier, une règle) vont entre « ». La hiérarchie des menus garde `›`.
- Les spécificateurs de format (`%@`, `%lld`, `%2$@`, `%#@name@`), les URL, le code, les noms d’API (fetch, XMLHttpRequest, WebSocket, CORS), les symboles de touches (⌘T) et les noms de marque (Zigzag, Arc, Chrome, Safari, Firefox, macOS, iCloud, Google, GitHub, 1Password) restent tels quels. Pour changer l’ordre des arguments, utilisez leur numéro d’origine (`%1$@`, `%2$@`).
- Pluriel : catégories CLDR `one` et `other`. En français, `one` couvre 0 et 1 : « 0 onglet », « 1 onglet », « 3 onglets ». Quand l’anglais omet le nombre dans `one` (« Close Tab »), le français peut faire de même (« Fermer l’onglet »).
- Les noms de langue fournis par le système sont en minuscules (« anglais ») et sans article ; tournez la phrase pour les placer après un deux-points ou après « en » (« Cette page est en %@ », « Toujours traduire : %@ »).
- Les mots-clés de recherche des Réglages (chaînes non affichées) sont traduits en français ; les termes techniques que l’on tape aussi en anglais (mcp, pip, oled, headless, devtools) et les noms de produits restent.
- Orthographe : e-mail, Wi-Fi, Internet, le Web, un site web, mini-lecteur.
- Élision devant un spécificateur : le nom inséré peut commencer par une voyelle (Arc, Edge, Orion, uBlock, apple.com, un nom de profil). Ne laissez jamais « de %@ », « que %@ », « le %@ » devant un nom ; tournez la phrase : « du site %@ », « du profil %@ », « de l’extension %@ », « enregistrés dans %@ », « Dans %@, exportez-les… », ou un deux-points. Les dates et les nombres (« le %@ » pour une date, « de %lld ») ne posent pas de problème.
- Accord avec un spécificateur : quand le genre ou le nombre de l’élément inséré est inconnu (une liste de fonctions, plusieurs noms), placez-le après un deux-points (« Non disponible dans Zigzag : %@. »).
- Split View prend l’article : « la Split View », « Voilà la Split View ».
