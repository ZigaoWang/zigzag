# 変更履歴

ZigzagのリリースノートをCHANGELOG.mdから日本語に翻訳したものです。Appには使用中のバージョンのノートが表示され、[zigzagbrowser.com/release-notes](https://zigzagbrowser.com/release-notes)ではすべてのバージョンを見られます。0.10.0より前のバージョンは英語で[CHANGELOG.md](../../../CHANGELOG.md)にあります。

## [Unreleased]

### 新機能
- 「設定 › 一般」の「iCloudと同期」で、スペース、プロファイル、固定タブ、フォルダ、お気に入り、ライブフォルダ、設定が、同じiCloudにサインインしているすべてのMacで同じ状態に保たれます。データはあなた自身のiCloudのプライベートデータベースに保存されます。開いているタブ、履歴、Webサイトのデータ、機能拡張はMacごとに残り、パスワードはこれまでどおりiCloudキーチェーンで同期されます。オンにすると、このMacのライブラリとiCloudのライブラリがひとつにまとまります。両方にあるものは新しいほうの編集が優先され、確認なしに削除されるものはなく、先にバックアップが保存されます。 ([#459](https://github.com/ZigaoWang/zigzag/issues/459))

### 変更
- 「サイトコントロール」の「このサイト」で、互換モードが最初の行になりました。オフにする項目の行より上に表示されます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#497](https://github.com/ZigaoWang/zigzag/issues/497))

## [0.10.0] - 2026-11-25

Zigzagが日本語、韓国語からドイツ語、フランス語、スペイン語、ロシア語まで、新たに13の言語に対応しました。ダウンロードルールで保存したファイルを受け渡せるようになり、ライブフォルダには最後に更新した時刻が表示されます。また、中国語のピンインで入力してから英語に切り替えても、余計なスペースが入らなくなりました。

### 新機能
- Zigzagが日本語に対応しました。macOSとSafariで使われているAppleの日本語の用語に合わせています。Macの言語に従うほか、「設定 › 一般 › 言語」で選ぶこともできます。
- Zigzagが韓国語、ドイツ語、フランス語、イタリア語、スペイン語、ポルトガル語（ブラジル）、ロシア語、オランダ語、ポーランド語、トルコ語に対応しました。それぞれAppleの用語に合わせています。Macの言語に従うほか、「設定 › 一般 › 言語」で選ぶこともできます。
- ダウンロードルールで、アドレスの代わりにファイルを受け渡せるようになりました。「渡すもの」を「ファイル」にすると、Zigzagはまずページのセッションでファイルをダウンロードし、保存したファイルをApp、スクリプト、サービスに渡します。リンクはこれまでどおりアドレスを受け渡します。ファイルを受け渡すときのテンプレートでは、保存したファイルに{file}または{file_url}を使えます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#529](https://github.com/ZigaoWang/zigzag/issues/529))
- ライブフォルダのメニューの先頭に、最後に更新した時刻が「5 分前に更新」のように表示されるようになりました。取得中は「更新中…」と表示されます。
- 「新規ライブフォルダ」と「ライブフォルダを編集」のシートは、最初にソースを尋ね、メニューを入力欄にそろえ、その下にフォルダに表示される内容と、30分ごと（低電力モードでは1時間ごと）に確認することを示します。名前を空のままにすると付けられる名前が表示され、GitHubで使えないユーザ名には印が付きます。
- 「サイトコントロール」に互換モードを追加しました。正しく動かないサイト向けで、スイッチ1つで、そのサイトの機能拡張、広告ブロック、Cookieバナー、非表示にした要素をオフにでき、オフにすると、それらに対して行った選択がすべて元に戻ります。オンのあいだは「サイトコントロール」がアクセントカラーで表示され、「設定 › プライバシー › サイト」にも一覧表示されます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。 ([#497](https://github.com/ZigaoWang/zigzag/issues/497))
- 「設定 › 外観 › リンクにポインタを置いたときにアドレスを表示」を追加しました。オフにすると、リンクにポインタを置いてもページの隅にバーが表示されません。ブラウザウインドウ、Zigzag Mini、Webアプリ、タブの概要で同じです。オフにするまではオンのままです。[sarekhamri](https://github.com/sarekhamri)さん、ありがとうございます。 ([#537](https://github.com/ZigaoWang/zigzag/issues/537))
- 「設定 › 外観 › フローティングサイドバーを短くする」を追加しました。サイドバーを隠しているとき、ページの上に出てくるサイドバーがウインドウの高さの3分の2になり、上下に6分の1ずつ空きます。固定されたサイドバーは変わりません。オンにするまではオフです。[sarekhamri](https://github.com/sarekhamri)さん、ありがとうございます。 ([#538](https://github.com/ZigaoWang/zigzag/issues/538))
- 「設定 › 外観 › 固定タブをタイルで表示」を追加しました。フォルダの外にある固定タブが、お気に入りの下にタイルで表示されます。お気に入りと同じグリッドの中に細い線をはさんで並び、開く、アンロードする、メニューを表示する、ドラッグするといった操作は、これまでの行と同じようにできます。フォルダとその中のページは行のままです。オンにするまではオフです。[sarekhamri](https://github.com/sarekhamri)さん、ありがとうございます。 ([#539](https://github.com/ZigaoWang/zigzag/issues/539))
- 「設定」の長いリストが、「サイトのアクセス許可」と同じようにボックスに折りたたまれるようになりました。対象は、「ショートカット」の各メニュー、保存した回答を中に収めた各ダウンロードルール、機能フラグの各種類、そして項目が3つを超えたときの「デベロッパモードのサイト」「信頼済みの証明書」「ページサイズ」です。「設定を検索」では、一致した項目があるボックスがこれまでどおり開きます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。 ([#536](https://github.com/ZigaoWang/zigzag/issues/536))
- 「サイトのアクセス許可」の検索と「設定を検索」で、サイトを許可や選択から探せるようになりました。「カメラ」「通知」「拒否」などと入力すると、その選択をしたすべてのサイトが、サイト名の下に表示されます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。 ([#532](https://github.com/ZigaoWang/zigzag/issues/532))
- 履歴の検索はアクセントと大文字・小文字を区別せず、すべての単語を順不同で見つけて強調表示し、一致した項目がまとめられた行の中に隠れることもありません。1日の時間帯ごとに見出しが1つ付き、同じサイトの2ページは2行のままで、リストは矢印キー、Delete、⌘Return、⌘Fに反応し、右クリックでサイト全体を削除できます。
- ライブフォルダが新しいページを確認している間、アイコンのバッジに回転するリングが表示されます。メールがメールボックスを確認するときと同じように、確認が終わるとすぐに止まります。
- 「新規ライブフォルダ」と「ライブフォルダを編集」のシートに、サイドバーと同じフォルダのアイコンが表示されるようになりました。GitHubのリストならGitHubの、フィードならサイトの、選んだアイコンがあればそのアイコンです。クリックすると「アイコンを変更…」と同じようにアイコンを変更でき、新しいフォルダは選んだアイコンで追加されます。

### 変更
- 2本指のスワイプによる戻る／進む操作がなめらかになりました。短い距離や軽いフリックでも動作し、ページが上下にずれることもなく、矢印が出たままになったりページがずれたままになったりすることもありません。タブ、Split View、Zigzag Miniで同じように動作します。

### 修正
- ページの上にZigzag Miniを開いているとき、暗くなったページの上でスクロールしても、後ろのページが動かなくなりました。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#531](https://github.com/ZigaoWang/zigzag/pull/531))
- WebサイトにこのMac上のAppへのアクセスを許可する前の説明で、手順が順番どおりに示されるようになりました。まずこの設定をオンにし、次に各サイトの「サイトコントロール」でそのサイトをオンにします。設定をオフにすると、すべてのサイトが止まります。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#533](https://github.com/ZigaoWang/zigzag/issues/533))
- 「設定」で、ボタンや検索が横にある見出しの下のリスト（「Webサイトが保存したデータ」や「ダウンロードとリンクの受け渡し」など）が、それらのコントロールのすぐ下から始まらなくなりました。ほかの見出しと同じ間隔が下に空きます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#527](https://github.com/ZigaoWang/zigzag/issues/527))
- 中国語のピンインから単語の途中で英語に切り替えても、ページやアドレスバーで文字のあいだにスペースが残らなくなりました。Chromeと同じ動作です。
- ガラスが「透明」の透けて見えるスペースで、Zigzagが何もしていないとき、空白のページや「設定」でもMacのグラフィックスが使われ続けることがなくなりました。macOSがウインドウ全体とその影を毎フレーム描き直していましたが、変化があるときだけ描くようになりました。アップデートカードの進行状況バーも、隠れているあいだは動かなくなりました。
- 「設定」が速く開くようになりました。各セクションの行は最初に開いたときに作られ、折りたたまれたボックスの行はボックスを開いたとき、または検索がその中を調べるときに作られます。そのため、「一般」で「設定」を開いても、「ダウンロード」「ショートカット」「デベロッパ」は作られません。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。 ([#536](https://github.com/ZigaoWang/zigzag/issues/536))
- Bitwardenの「生体認証でロック解除」がBitwardenのAppに届くようになりました。ZigzagはすでにAppと通信できるとBitwardenに伝えていたため、Bitwardenは許可を求めず、そのうえでZigzagがAppへの接続を止めていました。今はBitwardenが許可を求め、Zigzagが許可するかどうかを尋ねます。以前に生体認証をオンにしていた場合は、Bitwardenの設定で「生体認証でロック解除」をオフにしてからもう一度オンにしてください。[retorquere](https://github.com/retorquere)さん、ありがとうございます。 ([#484](https://github.com/ZigaoWang/zigzag/issues/484))
- アドレスバーをページの上に表示し、スペースを透明にしているとき、動画を再生してもMacのグラフィックスの負荷が、バーをオフにしたときよりずっと高くなることはなくなりました。ウインドウのガラスは、ウインドウ全体ではなくサイドバーの後ろにだけ残ります。
- Macのメモリが少ない状態で何時間もスリープしていたタブが、Azure DevOpsやMicrosoft 365などのサイトからログアウトした状態で復帰することはなくなりました。ログイン用のCookieを保持するWebKitの部分が、メモリ不足でmacOSによって停止された場合は、Zigzagがページを読み込む前にCookieを元に戻します。([#502](https://github.com/ZigaoWang/zigzag/issues/502))
- フルスクリーンの動画が、Bilibiliのように、サイト独自のトップバーやサイドの列で隠れることはなくなりました。([#543](https://github.com/ZigaoWang/zigzag/issues/543))
- ウインドウボタンが表示されていない場所に、戻る、進む、再読み込みボタンの左の空きが残ることはなくなりました。メニューバーが下りてくる前のフルスクリーンなどが該当します。また、短いフローティングサイドバーを開いている間も、ウインドウボタンはバーに残ります。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#542](https://github.com/ZigaoWang/zigzag/issues/542))
- 更新中に開いたままにしたライブフォルダのメニューが、閉じなくても「更新中…」から「たった今更新」、または更新できなかった理由に変わるようになりました。
- 「1行あたりのお気に入りの数」が「自動」のとき、お気に入りは各行に均等に配置されます。4個入る幅に6個ある場合は、4個と2個ではなく、3個ずつの2行になります。
