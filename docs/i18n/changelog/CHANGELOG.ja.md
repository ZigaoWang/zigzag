# 変更履歴

ZigzagのリリースノートをCHANGELOG.mdから日本語に翻訳したものです。Appには使用中のバージョンのノートが表示され、[zigzagbrowser.com/release-notes](https://zigzagbrowser.com/release-notes)ではすべてのバージョンを見られます。0.10.0より前のバージョンは英語で[CHANGELOG.md](../../../CHANGELOG.md)にあります。

## [Unreleased]

## [0.10.0] - 2026-11-25

Zigzagが日本語、韓国語からドイツ語、フランス語、スペイン語、ロシア語まで、新たに13の言語に対応しました。ダウンロードルールで保存したファイルを受け渡せるようになり、ライブフォルダには最後に更新した時刻が表示されます。また、中国語のピンインで入力してから英語に切り替えても、余計なスペースが入らなくなりました。

### 新機能
- Zigzagが日本語に対応しました。macOSとSafariで使われているAppleの日本語の用語に合わせています。Macの言語に従うほか、「設定 › 一般 › 言語」で選ぶこともできます。
- Zigzagが韓国語、ドイツ語、フランス語、イタリア語、スペイン語、ポルトガル語（ブラジル）、ロシア語、オランダ語、ポーランド語、トルコ語に対応しました。それぞれAppleの用語に合わせています。Macの言語に従うほか、「設定 › 一般 › 言語」で選ぶこともできます。
- ダウンロードルールで、アドレスの代わりにファイルを受け渡せるようになりました。「渡すもの」を「ファイル」にすると、Zigzagはまずページのセッションでファイルをダウンロードし、保存したファイルをApp、スクリプト、サービスに渡します。リンクはこれまでどおりアドレスを受け渡します。ファイルを受け渡すときのテンプレートでは、保存したファイルに{file}または{file_url}を使えます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#529](https://github.com/ZigaoWang/zigzag/issues/529))
- ライブフォルダのメニューの先頭に、最後に更新した時刻が「5 分前に更新」のように表示されるようになりました。取得中は「更新中…」と表示されます。
- 「新規ライブフォルダ」と「ライブフォルダを編集」のシートは、最初にソースを尋ね、メニューを入力欄にそろえ、その下にフォルダに表示される内容と、30分ごと（低電力モードでは1時間ごと）に確認することを示します。名前を空のままにすると付けられる名前が表示され、GitHubで使えないユーザ名には印が付きます。

### 修正
- ページの上にZigzag Miniを開いているとき、暗くなったページの上でスクロールしても、後ろのページが動かなくなりました。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#531](https://github.com/ZigaoWang/zigzag/pull/531))
- WebサイトにこのMac上のAppへのアクセスを許可する前の説明で、手順が順番どおりに示されるようになりました。まずこの設定をオンにし、次に各サイトの「サイトコントロール」でそのサイトをオンにします。設定をオフにすると、すべてのサイトが止まります。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#533](https://github.com/ZigaoWang/zigzag/issues/533))
- 「設定」で、ボタンや検索が横にある見出しの下のリスト（「Webサイトが保存したデータ」や「ダウンロードとリンクの受け渡し」など）が、それらのコントロールのすぐ下から始まらなくなりました。ほかの見出しと同じ間隔が下に空きます。[Lakeland97](https://github.com/Lakeland97)さん、ありがとうございます。([#527](https://github.com/ZigaoWang/zigzag/issues/527))
- 中国語のピンインから単語の途中で英語に切り替えても、ページやアドレスバーで文字のあいだにスペースが残らなくなりました。Chromeと同じ動作です。
- ガラスが「透明」の透けて見えるスペースで、Zigzagが何もしていないとき、空白のページや「設定」でもMacのグラフィックスが使われ続けることがなくなりました。macOSがウインドウ全体とその影を毎フレーム描き直していましたが、変化があるときだけ描くようになりました。アップデートカードの進行状況バーも、隠れているあいだは動かなくなりました。
