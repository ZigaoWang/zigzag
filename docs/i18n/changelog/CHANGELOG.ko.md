### 새로운 기능
- ‘설정 › 일반’의 ‘iCloud와 동기화’: 스페이스, 프로필, 고정된 탭, 폴더, 즐겨찾기, 라이브 폴더, 설정이 같은 iCloud에 로그인한 모든 Mac에서 똑같이 유지되며, 사용자 본인의 iCloud 비공개 데이터베이스에 보관됩니다. 열린 탭, 방문 기록, 웹 사이트 데이터, 확장 프로그램은 각 Mac에 남고, 암호는 계속 iCloud 키체인으로 동기화됩니다. 켜면 이 Mac의 라이브러리와 iCloud의 라이브러리가 합쳐집니다. 양쪽에 모두 있는 항목은 더 최근 편집이 적용되고, 묻지 않고 제거되는 항목은 없으며, 먼저 백업이 저장됩니다. ([#459](https://github.com/ZigaoWang/zigzag/issues/459))

## [0.10.0] - 2026-11-25

Zigzag가 일본어와 한국어부터 독일어, 프랑스어, 스페인어, 러시아어까지 13개 언어를 더 지원합니다. 다운로드 규칙으로 저장된 파일을 전달할 수 있고, 라이브 폴더는 마지막으로 업데이트된 시간을 표시하며, 중국어 병음으로 입력하다가 영어로 바꿔도 불필요한 공백이 생기지 않습니다.

### 새로운 기능
- 이제 Zigzag를 일본어로 사용할 수 있으며, macOS와 Safari에서 쓰는 Apple의 일본어 용어를 따릅니다. Mac의 언어를 따르거나 ‘설정 › 일반 › 언어’에서 고를 수 있습니다.
- 이제 Zigzag를 한국어, 독일어, 프랑스어, 이탈리아어, 스페인어, 포르투갈어(브라질), 러시아어, 네덜란드어, 폴란드어, 튀르키예어로 사용할 수 있으며, 언어마다 Apple의 용어를 따릅니다. Mac의 언어를 따르거나 ‘설정 › 일반 › 언어’에서 고를 수 있습니다.
- 다운로드 규칙이 주소 대신 파일을 전달할 수 있습니다. ‘전달’을 ‘파일’로 설정하면 Zigzag가 먼저 페이지의 세션으로 파일을 다운로드한 다음, 저장된 파일을 앱, 스크립트 또는 서비스에 넘깁니다. 링크는 여전히 주소를 전달하며, 파일 전달의 템플릿에서는 저장된 파일에 {file} 또는 {file_url}을 쓸 수 있습니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#529](https://github.com/ZigaoWang/zigzag/issues/529))
- 라이브 폴더의 메뉴 맨 위에 마지막으로 업데이트된 시간이 ‘5분 전 업데이트됨’처럼 표시되고, 가져오는 동안에는 ‘업데이트 중…’으로 표시됩니다.
- ‘새로운 라이브 폴더’와 ‘라이브 폴더 편집’ 시트는 소스를 먼저 묻고, 메뉴를 입력란에 맞춰 정렬하며, 그 아래에 폴더에 표시될 내용과 30분마다(저전력 모드에서는 1시간마다) 확인한다는 것을 알려 줍니다. 이름을 비워 두면 붙게 될 이름이 표시되고, GitHub에서 쓸 수 없는 사용자 이름에는 표시가 붙습니다.
- ‘사이트 제어’에 호환성 모드가 생겼습니다. 제대로 작동하지 않는 사이트를 위한 기능으로, 스위치 하나로 그 사이트의 확장 프로그램, 광고 차단, 쿠키 배너, 숨긴 요소를 끄고, 끄면 그것들에 대해 해 둔 선택이 모두 돌아옵니다. 켜져 있는 동안 ‘사이트 제어’가 강조 색으로 표시되고, ‘설정 › 개인정보 보호 › 사이트’에도 나타납니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#497](https://github.com/ZigaoWang/zigzag/issues/497))
- ‘설정 › 모양 › 링크 위에 포인터를 올리면 주소 표시’가 생겼습니다. 끄면 링크 위에 포인터를 올려도 페이지 모서리에 막대가 나타나지 않으며, 브라우저 윈도우, Zigzag Mini, 웹 앱, 탭 개요에서 모두 같습니다. 끄기 전까지는 켜져 있습니다. [sarekhamri](https://github.com/sarekhamri) 님께 감사드립니다. ([#537](https://github.com/ZigaoWang/zigzag/issues/537))
- ‘설정 › 모양 › 플로팅 사이드바 짧게 표시’가 생겼습니다. 사이드바를 숨긴 상태에서 페이지 위로 나오는 사이드바가 윈도우 높이의 3분의 2가 되고, 위아래로 6분의 1씩 비워 둡니다. 고정된 사이드바는 그대로입니다. 켜기 전까지는 꺼져 있습니다. [sarekhamri](https://github.com/sarekhamri) 님께 감사드립니다. ([#538](https://github.com/ZigaoWang/zigzag/issues/538))
- ‘설정 › 모양 › 고정된 탭을 타일로 표시’가 생겼습니다. 폴더 밖에 있는 고정된 탭이 즐겨찾기 아래에 타일로 표시되며, 즐겨찾기와 같은 격자 안에서 가는 선을 사이에 두고 놓입니다. 열기, 로드 해제, 메뉴 표시, 드래그는 기존의 행과 똑같이 됩니다. 폴더와 그 안의 페이지는 그대로 행으로 남습니다. 켜기 전까지는 꺼져 있습니다. [sarekhamri](https://github.com/sarekhamri) 님께 감사드립니다. ([#539](https://github.com/ZigaoWang/zigzag/issues/539))
- 설정의 긴 목록이 ‘사이트 권한’처럼 상자로 접힙니다. ‘단축키’의 각 메뉴, 저장된 답변을 안에 담은 각 다운로드 규칙, 각 종류의 기능 플래그, 그리고 항목이 세 개를 넘을 때의 ‘개발자 모드인 사이트’, ‘신뢰하는 인증서’, ‘페이지 크기’가 해당합니다. ‘설정 찾기’는 일치하는 항목이 있는 상자를 전과 같이 엽니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#536](https://github.com/ZigaoWang/zigzag/issues/536))
- ‘사이트 권한’의 자체 검색과 ‘설정 찾기’가 이제 권한과 선택으로도 사이트를 찾습니다. 카메라, 알림 또는 차단을 입력하면 그 선택을 한 모든 사이트가 사이트 이름 아래에 하나씩 표시됩니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#532](https://github.com/ZigaoWang/zigzag/issues/532))
- 방문 기록 검색은 악센트와 대소문자를 구분하지 않고, 모든 단어를 순서와 상관없이 찾아 표시하며, 일치하는 항목이 묶음 안에 숨는 일도 없습니다. 하루의 시간대마다 제목이 하나씩 있고, 같은 사이트의 두 페이지는 두 행으로 남으며, 목록은 화살표 키, Delete, ⌘Return, ⌘F와 사이트 전체를 제거하는 오른쪽 클릭에 반응합니다.
- 라이브 폴더가 새 페이지를 확인하는 동안 아이콘의 배지에 도는 고리가 표시됩니다. Mail이 메일함을 확인할 때처럼 표시되며, 확인이 끝나면 바로 멈춥니다.
- ‘새로운 라이브 폴더’와 ‘라이브 폴더 편집’ 시트에 사이드바와 같은 폴더 아이콘이 표시됩니다. GitHub 목록이면 GitHub의 아이콘, 피드면 사이트의 아이콘, 직접 고른 아이콘이 있으면 그 아이콘입니다. 클릭하면 ‘아이콘 변경…’처럼 아이콘을 바꿀 수 있고, 새 폴더는 고른 아이콘으로 추가됩니다.

### 변경 사항
- 두 손가락으로 쓸어 넘겨 뒤로 가거나 앞으로 가는 동작이 더 부드러워졌습니다. 더 짧은 거리나 가벼운 쓸기에도 동작하고, 페이지가 위아래로 밀리지 않으며, 화살표가 남아 있거나 페이지가 어긋난 채로 남는 일도 없습니다. 탭, Split View, Zigzag Mini에서 모두 같습니다.

### 수정 사항
- 페이지 위에 Zigzag Mini를 열었을 때 어두워진 페이지 위에서 스크롤해도 뒤에 있는 페이지가 더 이상 움직이지 않습니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#531](https://github.com/ZigaoWang/zigzag/pull/531))
- 웹 사이트가 이 Mac의 앱에 접근하도록 허용하기 전의 안내가 이제 단계를 순서대로 알려 줍니다. 먼저 설정을 켠 다음 각 사이트의 ‘사이트 제어’에서 그 사이트를 켜고, 설정을 끄면 모든 사이트가 중지됩니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#533](https://github.com/ZigaoWang/zigzag/issues/533))
- 설정에서 ‘웹 사이트가 저장한 데이터’나 ‘다운로드 및 링크 전달’처럼 제목 옆에 버튼이나 검색이 있는 목록이 더 이상 그 컨트롤 바로 아래에서 시작하지 않습니다. 다른 제목과 같은 간격을 그 아래에 둡니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#527](https://github.com/ZigaoWang/zigzag/issues/527))
- 중국어 병음에서 단어 중간에 영어로 바꿔도 페이지나 주소 막대에서 글자 사이에 공백이 남지 않습니다. Chrome과 같습니다.
- 유리가 ‘투명’인 비치는 스페이스에서 Zigzag가 아무것도 하지 않을 때, 빈 페이지나 설정에서도 더 이상 Mac의 그래픽 처리를 계속 붙잡아 두지 않습니다. macOS가 매 프레임마다 윈도우 전체와 그림자를 다시 그리고 있었는데, 이제 무언가 바뀔 때만 그립니다. 업데이트 카드의 진행 막대도 가려져 있는 동안에는 움직이지 않습니다.
- 설정이 더 빨리 열립니다. 각 섹션의 행은 처음 열 때 만들어지고, 접힌 상자의 행은 상자를 열거나 검색이 그 안을 살펴볼 때 만들어지므로, 일반에서 설정을 열어도 더 이상 다운로드, 단축키, 개발자를 만들지 않습니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#536](https://github.com/ZigaoWang/zigzag/issues/536))
- Bitwarden의 ‘생체 인식으로 잠금 해제’가 이제 Bitwarden 앱에 연결됩니다. Zigzag가 Bitwarden에 앱과 이미 통신할 수 있다고 알려서 Bitwarden이 허용을 요청하지 않았고, 그다음에는 Zigzag가 앱 연결을 막고 있었습니다. 이제 Bitwarden이 요청하고 Zigzag가 허용할지 묻습니다. 전에 생체 인식을 켜 두었다면 Bitwarden 설정에서 ‘생체 인식으로 잠금 해제’를 껐다가 다시 켜세요. [retorquere](https://github.com/retorquere) 님께 감사드립니다. ([#484](https://github.com/ZigaoWang/zigzag/issues/484))
- 주소 막대를 페이지 위에 두고 스페이스를 투명하게 했을 때, 재생 중인 동영상이 막대를 끈 때보다 Mac의 그래픽을 훨씬 많이 쓰지 않습니다. 이제 윈도우의 유리는 윈도우 전체가 아니라 사이드바 뒤에만 남습니다.
- Mac의 메모리가 부족한 상태에서 몇 시간 동안 잠들어 있던 탭이 Azure DevOps나 Microsoft 365 같은 사이트에서 로그아웃된 채로 깨어나는 일이 없어졌습니다. 메모리가 부족할 때 macOS가 로그인 쿠키를 보관하는 WebKit 부분을 멈추게 하면, Zigzag가 페이지를 불러오기 전에 쿠키를 되돌려 놓습니다. ([#502](https://github.com/ZigaoWang/zigzag/issues/502))
- 전체 화면 동영상이 Bilibili처럼 사이트 자체의 상단 막대나 옆 열에 가려지지 않습니다. ([#543](https://github.com/ZigaoWang/zigzag/issues/543))
- 윈도우 버튼이 표시되지 않는 곳에서 뒤로, 앞으로, 다시 로드 버튼 앞에 빈 공간이 남지 않습니다. 메뉴 막대가 내려오기 전의 전체 화면이 그런 경우입니다. 또 더 짧은 떠 있는 사이드바가 나와 있는 동안에도 윈도우 버튼은 막대에 그대로 있습니다. [Lakeland97](https://github.com/Lakeland97) 님께 감사드립니다. ([#542](https://github.com/ZigaoWang/zigzag/issues/542))
- 업데이트하는 동안 열어 둔 라이브 폴더의 메뉴가 이제 닫히지 않고 ‘업데이트 중…’에서 ‘방금 업데이트됨’ 또는 새로 고칠 수 없는 이유로 바뀝니다.
- ‘행당 즐겨찾기 수’가 ‘자동’일 때 즐겨찾기가 행마다 고르게 나뉩니다. 네 개가 들어갈 자리에 여섯 개가 있으면 네 개와 두 개가 아니라 세 개씩 두 행이 됩니다.
