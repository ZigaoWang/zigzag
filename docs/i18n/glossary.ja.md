# 日本語用語集

Zigzag の日本語インターフェイスは `ja` です。意味は英語の原文と各文字列のコメントで確かめてください。中国語訳は参考になりますが、そこから訳さないでください。macOS や Safari に同じ機能がある場合は、Apple の日本語の用語を使います。

- 完全な文は「です・ます」で書きます。ボタンとメニュー項目は短い名詞句か動詞の辞書形にします（「新規タブ」「タブを閉じる」）。見出しやラベルも名詞句です。
- 「あなた」は使いません。日本語では主語を省くのが自然です。必要なときは「自分の」を使います。
- 句読点は全角の「。」「、」を使います。「（）」「：」「？」「！」も全角です。英語だけの文は英語の句読点のままです。
- ボタン名、メニューのパス、ユーザが付けた名前は「」で囲みます。中の引用は『』です。メニューの階層は Zigzag と同じ `›` を使い、一組の「」に入れます（「設定 › 一般」）。“” は使いません。
- 日本語と英字・数字のあいだにスペースを入れません（「Chromeから読み込む」「3個のタブ」）。Apple の日本語と同じです。英単語同士のスペースはそのままです（「Zigzag Mini」）。
- 省略記号は `…` 一文字です（「共有…」）。
- カタカナの長音は Apple の表記に合わせます：フォルダ、ブラウザ、ユーザ、サーバ、デベロッパ、コンピュータ、フィルタ、パラメータ。短い語やよく知られた語は長音を付けます：バー、キー、エラー、プレーヤー、トラッカー、メモ。「ウィンドウ」ではなく「ウインドウ」です。
- 数え方：タブ、ウインドウ、スペース、フォルダ、機能拡張、プロファイルなどは「個」、パスワード、ブックマーク、履歴、Cookie、ダウンロードなどの記録は「件」、サイトは「個のサイト」です。数字と助数詞のあいだにスペースはありません。
- `%@`、`%lld`、`%2$@`、`%#@name@` などの書式指定子、URL、コード、キーの記号（⌘T）、ブランド名（Zigzag、Arc、Chrome、Safari、macOS、iCloud、Google、1Password）はそのまま残します。語順のために引数の順番を変えるときは、`%1$@`、`%2$@` のように元の番号を使います。
- 日本語の複数形は `other` だけです。「1個のタブを閉じる」と「3個のタブを閉じる」は同じ書式を使います。
